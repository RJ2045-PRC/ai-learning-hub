# AI 知识库

每天北京时间 7:30 开始生成日报，完成后归档。

## 阅读入口

- [能力建立路线图](能力路线图.md)：从模型基础、Python与FastAPI，到RAG、框架、数据库、本地模型及完整落地；每日课程依此逐步推进。

- [日报索引](日报索引.md)：按日期阅读，每篇约 15 分钟。
- `概念/`：随学习积累的概念笔记，日报通过相对链接引用。
- [学习进度](学习进度.md)：记录已介绍内容、明确反馈及后续路线。

日报一半追踪最新进展，一半系统学习，附原始来源与一道可选理解题。

## 可视化学习台

打开 [学习台.html](学习台.html)，可以离线阅读完整日报，按日期、主题、关键词检索，查看概念笔记、学习路线与互动流程图。每日归档后会重新生成此文件，刷新页面即可看到更新。

- 内容源：`日报/`、`概念/`、`学习进度.md`。
- 图解内容：`学习台资源/图解.json`，以日报日期为键；每个图解包含标题、介绍、步骤及边界说明。步骤记录名称、对应概念、解释与可能的失败点。
- 路线内容：`学习台资源/学习路线.json`，记录每一阶段的主题、描述和状态；状态需依据学习进度与真实反馈调整。
- 固定模板：`学习台资源/模板.html`；布局与交互复用，日常新增内容不必重写模板。
- 重建入口：`学习台资源/生成学习台.cjs`，汇总全部 Markdown、图解与路线，生成自包含 HTML；只覆盖生成页，不覆盖原始笔记。

当前电脑的重建方式：

```sh
node 学习台资源/生成学习台.cjs
```

首次在新电脑运行先执行 `npm ci`，之后用 `npm run build` 重建学习台与公开站点。生成器依赖 Node.js 和项目锁定的 marked，无需本机专用路径。生成的 HTML 仍可离线打开。

## 公开阅读与自动发布

- 在线入口：https://rj2045-prc.github.io/ai-learning-hub/
- 内容仓库：https://github.com/RJ2045-PRC/ai-learning-hub
- 当前采用本机 Codex 生成、GitHub 保存、GitHub Pages 公开阅读，不需要额外模型 API Key。
- 每日保存并检查知识库后执行 `npm run publish:daily`。首次已配置 GitHub Pages 从 main 分支 docs/ 发布；上传后仍须检查部署结果及线上日期。
- 电脑需开机联网且 Codex 运行；网页已发布的历史内容可随时在其他设备阅读。
- 公开仓库包含学习进度及反馈记录。不要写入密钥、私人资料或仅限本机使用的绝对路径。
- 多设备浏览器的已读标记目前各自保存；理解题仍在原聊天回答，由本机任务写入学习进度后发布。
- 发布脚本遇到远端更新或推送失败会停止；不要强推覆盖。未核验部署前不能声称线上已更新。


阅读标记只存于当前浏览器，换浏览器或清除数据后可能丢失，也不会自动反馈给每日任务。理解情况仍以聊天反馈和学习进度记录为准。
