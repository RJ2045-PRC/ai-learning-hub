# Embedding、相似性与事实性

## 定义

在文本检索中，Embedding模型把文字编码成数字向量；用兼容的编码方式和相似度度量比较查询与资料，寻找候选。这里讨论文本语义检索，不涵盖全部Embedding用途。

## 例子

“如何记住偏好”与“保存并召回长期个人信息”表达不同但可能相关。“周日开放”与“周日不开放”谈论相同对象却结论相反，可能同时成为候选。具体排序取决模型与语料，未实测，不提供虚构分数。

## 边界

- 相似度不是事实正确的概率，0.95不等于95%可信；分数意义依模型和度量。
- 向量维度通常不是可直接命名的语义标签，不是可逆的原意编码，也不是反向扩散追溯元语义。
- 原文供核验，元数据限定来源/日期/版本/对象，向量帮助查找；三者需对应并随修改同步。
- 找到相关候选后还要判断适用性、原文支持和冲突；提高阈值不能替代这些检查。
- 文字排序、向量检索、条件筛选可组合；是否改善须用任务题目验证。
