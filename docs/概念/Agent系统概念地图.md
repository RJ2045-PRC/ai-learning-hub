# Agent 系统概念地图

首次介绍：2026-10-18。状态：已介绍，尚未通过反馈确认理解。

| 概念 | 入门解释 | 主要边界 |
| --- | --- | --- |
| 模型 | 理解信息并生成判断或内容的组件 | 不等于完整的任务执行系统 |
| Agent | 围绕目标、依据反馈选择动作的系统 | 自主程度不同，经常与固定工作流混用 |
| Loop | 行动后观察结果，再决定继续、改变动作或结束 | 单纯定时重复不等于任务内反馈循环 |
| Harness | 连接模型、工具、状态与执行规则的运行支撑 | 不同产品对范围的定义不同 |
| RAG | 先检索外部资料，再辅助生成 | 检索、资料与解读仍可能出错 |
| 记忆 | 保留、更新和使用过去信息的机制 | 保存文件不代表下次一定读取或正确使用；可与检索结合 |

例子：日报先读取学习进度，检索来源，发现不足后补查，完成后保存文件并更新进度。
